BUTTON NAMES:
  A, B, X, Y             Face buttons (Xbox convention in config)
  DPadUp/Down/Left/Right D-pad
  LB, RB                 Bumpers (shoulders)
  LT, RT                 Triggers

  Home                   Home/Mode button
