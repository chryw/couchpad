# Security Policy

## Reporting a Vulnerability

If you find a security issue, please email chryw@users.noreply.github.com instead of opening a public issue.

I'll respond within a few days and work with you on a fix before any public disclosure.

## Scope

Couchpad runs locally and has no network access, no telemetry, and no remote code execution surface. The main security-relevant area is the keyboard emitter (requires Accessibility permission on macOS).
